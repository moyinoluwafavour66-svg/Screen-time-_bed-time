### Business Question
How do late-night phone habits create sleep debt and impact next-day health?

### Tools
R, readr, dplyr, ggplot2, cor()

### Analysis Done
- Loaded & cleaned 8,500 records
- EDA: bedtime_phone_minutes distribution
- Visual 1: Total sleep hours vs phone minutes
- Visual 2: Sleep latency by app (TikTok worst)
- Visual 3: Blue light filter impact (-18 min faster sleep)

### Key Insight for Health Stakeholders
Limit bedtime phone to <20 min + enable blue light filter + avoid TikTok/IG 1hr before bed → 30% less sleep debt.
